# 🌤️ WeatherPulse

## Real-Time Weather Intelligence Dashboard

WeatherPulse is a modern real-time weather dashboard developed using HTML, CSS and JavaScript.

The application uses asynchronous JavaScript and public REST APIs to retrieve live weather information for cities around the world.

---

## 🚀 Project Objective

The main objective of WeatherPulse is to create an interactive weather dashboard that demonstrates:

- REST API integration
- Fetch API
- Async/Await
- JSON data handling
- DOM manipulation
- Local Storage
- Responsive web design
- Error handling
- Dynamic UI updates

---

# ✨ Features

## 1. City Search

Users can search for any city and retrieve its current weather information.

Example:

- Chennai
- Bengaluru
- Mumbai
- Delhi
- London

---

## 2. City Autocomplete

When the user starts typing a city name, WeatherPulse automatically retrieves matching locations from the geocoding API.

---

## 3. Real-Time Weather

The dashboard displays:

- Current temperature
- Weather condition
- Feels-like temperature
- Humidity
- Wind speed
- Rain amount
